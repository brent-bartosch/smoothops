This folder is the single home for LinkedIn **profile** positioning strategy (how recruiters and founders find and read you). It is user-layer content — never touched by career-ops system updates.

Posting drives inbound DMs, not search rank.** Two different machines.

## The positioning history in one paragraph

Overhaul #1 optimized for the term recruiters search most ("GTM Engineer") and it worked — but it worked at sorting Brent into the **$175–200K IC pool**, because "GTM Engineer" is an IC keyword. Overhaul #2 (2026-07) reversed the lead: leadership identity first, engineering as the edge. Overhaul #3 (2026-10, v2) keeps that reversal but updates the target set: senior GTM-engineering seats now exist (Head of GTM Engineering, AI-GTM roles), the searches for them screen for *production* evidence, and the client work since July (deployed multi-agent pipelines with QA gates and human-approval hinges) is exactly that evidence. v2 = leadership framing + frontier proof, aimed at both query patterns.
